# 品質保証の記録

全員で使う。各ファイルは期間ごとに追記する。

- `scenarios.md` … 会話のテストシナリオと結果（QA-4-1〜）
- `security-checklist.md` … セキュリティ確認表（QA-4-3〜）
- `ux-metrics.md` … 体験の計測（応答時間・使いやすさ）（QA-3-2〜）
- `manual-checks.md` … 実機でしか確かめられない確認（マイク・スピーカー・GPU）

## セキュリティ確認の観点（初版）
- [ ] すべてのサーバーが 127.0.0.1 だけで待ち受けている（`lsof -iTCP -sTCP:LISTEN`）
- [ ] トークン・API キーがリポジトリ・ログ・画面に出ていない
- [ ] OpenClaw のトークンがブラウザに渡っていない（DevTools の Network で確認）
- [ ] 承認しないと、タスク・予定が変わらない
- [ ] 公開マーケットのスキルを使っていない
- [ ] クラウド AI を使う前に、画面で同意を取っている
