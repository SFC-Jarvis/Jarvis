# プロジェクト概要

## 何を作るか
**JARVIS**: ChatGPT のような画面で、声でもテキストでも話せる自分専用の AI エージェント。自分の PC の中で動く。

- 会話はすべて JARVIS のアプリの中で行う（外部のチャットアプリは使わない）
- タスク・予定を声や文字で追加・完了できる。**追加・変更・削除は承認カードで確認してから実行**
- アプリの起動時、または設定した時刻（アプリ起動中）に「今日のブリーフ」を読み上げる

## 今学期のゴール: MVP（第 13 週・2027-01-14）
完成条件（すべて満たしたら MVP 完成）:
1. ブラウザの画面と声の両方で会話できる
2. タスクと予定を追加・完了できる（承認してから反映）
3. 起動時と設定した時刻に、今日のブリーフを読み上げる
4. データは PC 内に保存し、3 人全員の PC で動く

MVP では作らないもの: デスクトップアプリ化、呼びかけでの起動、開発用サーバー、応答速度の最適化

## 次学期: 初期リリース
デスクトップアプリ（Windows・Mac）と初回セットアップ / 強い GPU がなくても無料の AI を自動で選んで使う /
呼びかけで起動・応答の高速化 / 同意したデータだけを改善のために開発用サーバーへ送る

## データとプライバシーの方針
| 置き場所 | 何を | ルール |
|---|---|---|
| 端末の中 | 会話の履歴・記憶・タスク・予定 | 暗号化して保存（鍵は OS のキーチェーン）。ユーザーがいつでも全部消せる |
| クラウドの AI（使うときだけ） | その会話の内容 | PC 内の Ollama を最優先。Gemini 無料枠は内容が製品改善に使われるため画面で明示し、同意してから使う |
| 開発用サーバー（初期リリースから） | 同意したデータだけ（エラー情報・応答時間・評価） | 会話の本文は送らない。同意はいつでも取り消せる。利用目的・保存期間・削除依頼の対応を決めてから作る |

## 技術スタックと選定理由（要約）
- **OpenClaw**（頭脳）: 会話・記憶・定期実行・MCP が標準で入っている。OpenAI 互換 API で自作の画面とつなぎやすい。AI を入れ替えやすい。MIT ライセンス
- **考える AI**: Ollama + Qwen3.5（PC 内・最優先）、無料のクラウド AI（Gemini Flash など）は同意してから
- **音声**: Pipecat（発話検出 Silero VAD、文字起こし kotoba-whisper / Qwen3-ASR を比較、読み上げ AivisSpeech）
- **画面**: Next.js（localhost）→ 次学期に Electron でアプリ化
- **データ**: SQLite（端末内）+ FastMCP（MCP サーバー）
- 公開マーケットのスキル（ClawHub）は使わない。スキルは自作する（過去に悪意あるスキルが大量に見つかったため）
