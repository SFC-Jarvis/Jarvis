担当: B ／ 状態: **案（全員の確認待ち）** ／ 実装: WEB-3-2（モック）→ WEB-4-1（OpenClaw とつなぐ）

見た目の案（案 2 コア 3 枚・案 1 チャット型 3 枚）: https://claude.ai/artifact/Ss8max8V6KftSS5qrbZ4nH

JARVIS の会話画面の設計。案は 2 つあり、**案 2（コア）を第一候補**にする。案 1 は ChatGPT 型の比較用。

## 0. 案 2: コア（粒子の球体）— 第一候補

真ん中に粒子でできた球体（コア）を置き、JARVIS の「顔」にする。スタイリッシュさと新しさを重視する。

```
┌──────────────────────────────────────────────────────┬──────────────────┐
│ JARVIS  PERSONAL AGENT            ● PC 内の AI  08:42 │ 会話の記録    ［＋］│
│                                                      │ TODAY            │
│                    ╭─ ─ ─ ─ ─ ─╮                     │ ▣ 今日の予定を… │
│                  ╱   · ∴ ∵ · ·   ╲                   │   08:41 · 声     │
│                 │  ∴ 粒子の球体 ∵ │  ← 状態で動きが変わる│   買い物リスト… │
│                  ╲   · ∵ ∴ · ·   ╱                   │ YESTERDAY        │
│                    ╰─ ─ ─ ─ ─ ─╯                     │   レポートの…   │
│                     SPEAKING                         │                  │
│                    話しています                       │ ┌ TODAY · 見本 ┐ │
│                                                      │ │ 2 予定 3 タスク│ │
│          YOU  今日の予定を教えて                      │ └──────────────┘ │
│   今日の予定は 2 件です。10 時から服部研究会、…▍       │                  │
│                会話の全文を見る ↓                     │                  │
│     ╭────────────────────────────────────╮  ( 🎤 )   │ ⚙ 設定           │
│     │ JARVIS に話しかける（Enter で送信） ➤│          │                  │
│     ╰────────────────────────────────────╯           │                  │
└──────────────────────────────────────────────────────┴──────────────────┘
                     本体                                     320px
```

- **コア（粒子の球体）**: 約 1,100 個の点を球面に並べ、`<canvas>` で描く。外側に細いリングの飾り（SVG）
  - 状態ごとに動きを変える: 待機＝ゆっくり回る・暗め ／ 聞く＝外へ波紋が広がる ／ 考える＝速く回り、周りに粒子の輪 ／ 話す＝表面が波打つ
  - 状態の名前を球体の下に文字でも出す（`STANDBY` `LISTENING` `THINKING` `SPEAKING` と日本語）。色や動きだけで伝えない
  - 「動きを減らす」設定（`prefers-reduced-motion`）の PC では止めて表示する
  - 描画は軽く保つ（60fps を目安。重ければ点の数を減らす）。新しい依存ライブラリは使わず、canvas 2D で描く
- **会話は字幕の形**: 球体の下に最新の 1 往復だけ出す（自分の発言は小さく灰色、JARVIS の返答は大きく）。「会話の全文を見る」で、案 1 と同じ一覧を下から重ねて開く
- **履歴は右の列（320px）**: 会話ごとに時刻と「声 / 文字」を出す。下に「今日のまとめ」（予定・タスクの数。WEB-4-2・WEB-5-1 で作る場所）
- **入力は下の中央**: 丸い入力欄と、大きなマイクボタン（64px）。声で使うことを主役にする
- **色**: ほぼ黒（#04060a）に薄い方眼。アクセントは水色（#38bdf8）。文字は等幅（JetBrains Mono）と Noto Sans JP
- 承認カード（WEB-5-1）は字幕の位置に出す。ブリーフ（WEB-5-1）は待機中の挨拶の位置に出す
- 部品の追加: `JarvisCore`（球体。`mode` を受け取る）・`Subtitle`（字幕）・`ConversationLog`（全文）。描画の計算（点の位置）は `src/lib/core.ts` に分けてテストする

以下の 1〜8 は案 1（チャット型）の設計。部品の分け方・操作・アクセシビリティ・テストの観点は案 2 でも同じものを使う。

## 1. 画面の構成（案 1）

```
┌────────────────┬──────────────────────────────────────────────┐
│ JARVIS         │ 今日の予定を教えて                 ⋯         │ ← 見出し（会話のタイトル）
│ ［＋ 新しい会話］│──────────────────────────────────────────────│
│                │                                              │
│ 今日           │ ◆ JARVIS                                      │
│ ▸ 今日の予定…  │   おはようございます。今日の予定は 2 件です。  │
│   買い物リスト │                                              │
│ 昨日           │                          今日の予定を教えて ▣ │ ← 自分（右寄せ）
│   レポートの…  │                                              │
│                │ ◆ JARVIS                                      │
│                │   10:00 研究会、15:00 ミーティングです。▍      │ ← 返答中（少しずつ表示）
│                │                                              │
│                │ ┌──────────────────────────────────────────┐ │
│                │ │ メッセージを入力（Enter で送信）     🎤 ➤ │ │ ← 入力欄
```

- 左（240px）: 会話の履歴。上に「新しい会話」、下に「設定」（WEB-6-2 まではリンクだけ）
- 右: 見出し・メッセージの一覧・入力欄。メッセージと入力欄は最大幅 768px で中央に置く（読みやすさのため）
- 色は今のダークテーマ（neutral 系）に合わせる。JARVIS の返答は背景なし、自分の発言は濃い灰色の吹き出し

## 2. 部品

`src/components/chat/` に置く。1 部品 1 ファイル、テストは同じフォルダに `*.test.tsx`。

| 部品 | 役割 | 主な props |
|---|---|---|
| `ChatView` | 会話 1 つ分の画面。送信と返答の状態を持つ | `conversation`, `sendMessage`（差し替え可。テストではモック） |
| `MessageList` | メッセージを順に並べ、最新へ自動スクロール | `messages`, `pending` |
| `MessageBubble` | 1 件の発言（自分 / JARVIS / エラー） | `message` |
| `Composer` | 入力欄と送信ボタン（後でマイクボタン） | `onSend`, `disabled` |
| `HistorySidebar` | 会話の一覧・新しい会話・切り替え | `conversations`, `activeId`, `onSelect`, `onNew` |

データの形（`src/lib/chat.ts` に型を置く）:

```ts
type Message = { id: string; role: 'user' | 'assistant'; content: string; createdAt: string; status?: 'sending' | 'error' };
type Conversation = { id: string; title: string; messages: Message[]; updatedAt: string };
```

- 会話 1 つにセッションキー（会話を続けるための ID）1 つ: `web:<会話ID>`（contracts/openclaw.md）
- 会話のタイトルは最初の発言の先頭 20 文字（後で AI に付けてもらうことも検討）
- 第3回は履歴をブラウザのメモリだけに持つ（再読み込みで消える）。保存は WEB-4-1 で決める

## 3. 状態ごとの見た目

| 状態 | 見た目 |
|---|---|
| 空の会話 | 中央に「何をお手伝いしましょうか？」と、例の質問 3 つ（押すと入力欄に入る）。例: 「今日の予定は？」「タスクを追加して」「今週の締め切りは？」 |
| 送信中（返答待ち） | 自分の発言をすぐ表示し、JARVIS 側に「考えています…」（点滅する 3 点）。送信ボタンは「停止」に変わる |
| 返答中（ストリーミング） | 届いた分から少しずつ表示し、末尾にカーソル ▍。第3回のモックは一括表示でよい |
| エラー | JARVIS 側に赤い枠で「返答を受け取れませんでした。」＋［もう一度送る］。原因（開発者向け）は画面に出さずコンソールへ |
| 長い返答 | 改行・箇条書きはそのまま表示。Markdown の表示は WEB-4-1 以降で検討 |

## 4. 操作

- **Enter で送信、Shift+Enter で改行。** 日本語の変換確定の Enter では送信しない（`isComposing` を見る）
- 空白だけのときは送信ボタンを押せない
- 送信中はもう一度送れない（二重送信を防ぐ）。「停止」で返答待ちを取り消す
- 入力欄は内容に合わせて最大 8 行まで伸びる
- 新しいメッセージが来たら一番下へスクロール。ただし、上を読んでいるときは動かさず「↓ 最新へ」を出す
- 会話を切り替えたら入力欄にフォーカスを移す

## 6. 狭い画面

- 幅 768px 未満では左の履歴を隠し、見出しの左に ☰ ボタンを出す（押すと上に重ねて開く）
- MVP は PC での利用が中心なので、狭い画面は「崩れない」ことだけを確かめる

## 7. アクセシビリティ（誰でも使いやすくする配慮）

- メッセージ一覧は `role="log"`、`aria-live="polite"` で、新しい返答をスクリーンリーダーが読む
- 入力欄に `aria-label="メッセージ"`、ボタンに「送信」「停止」「新しい会話」「録音を開始」などの名前を付ける
- 発言ごとに「あなた」「JARVIS」を見えない文字でも付ける（色だけで区別しない）
- キーボードだけで、送信・会話の切り替え・新しい会話ができる。フォーカスの枠を消さない
- 文字と背景のコントラスト比 4.5:1 以上

## 8. テストの観点（WEB-3-2 で書く）

- 文字を入れて Enter → 自分の発言が出て、モックの返答が出る
- Shift+Enter では送らず改行する。変換中の Enter では送らない
- 空のときは送信ボタンが押せない。送信中は二度送れない
- 返答が失敗したらエラーと［もう一度送る］が出て、押すと再送する
- 「新しい会話」で空の会話になり、履歴に前の会話が残る。履歴を押すとその会話に戻る
