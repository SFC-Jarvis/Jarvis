# 過去の Claude の記録を集めるプロンプト

`/done` で自動追記する前の記録を集めるときに使う。出てきた結果を、Mac の Claude Code（このリポジトリ）に貼り、「docs/ai-usage/<自分の ID>.md に統合して」と頼む。

## 1. Claude アプリ（claude.ai・デスクトップアプリ）用
JARVIS について話した**チャットごとに**、そのチャットの最後に貼る。過去のチャットを検索できる場合は、新しいチャットで「JARVIS」を検索して使ってもよい。

```text
この会話（JARVIS の開発・計画）で私が入力したプロンプトのうち、重要なものだけを一覧にしてください。

残すもの: 方針や仕様を決めたプロンプト、作業を指示したプロンプト（資料・スライド・計画の作成など）、問題の報告と対処の指示
残さないもの: 確認のための短い質問、要約の依頼、言い換えや語尾の調整、「はい」「OK」などの返事
同じ目的の短いやりとりが続いたときは 1 件にまとめてください。
トークン・API キー・パスワード・個人のデータは、その部分を省いてください。

次の形の markdown を、1 つのコードブロックだけで出力してください。プロンプトは原文の言語のまま、結果は日本語で書いてください。日付が分からなければ「（日付不明）」としてください。

### <日付> <目的>（Claude アプリ: <この会話の題名>）
> <プロンプトの原文。長い貼り付けは「（資料を貼り付け）」と書いて省く>

- 結果: <何が決まり、何ができたか>
```

## 2. Claude Code（Windows の WSL2 など、別の PC）用
その PC で、Jarvis のフォルダを開いて `claude` を起動し、次を貼る。Claude Code の会話記録（`~/.claude/projects/` の下）から集める。

```text
この PC の Claude Code の会話記録から、JARVIS の開発で私が入力した重要なプロンプトを一覧にしてください。

1. ~/.claude/projects/ の下から、フォルダ名に Jarvis を含むものを探し、その中の *.jsonl を古い順に読んでください。
   - 使うのは "type":"user" で、本文が文字列のもの（ツールの結果・システムのメッセージは除く）。
   - <command-name> のあるものは、コマンド名と引数だけを残す（例: /start DT-3-1）。
2. 残すもの: 方針や仕様を決めたプロンプト、作業を指示したプロンプト、不具合の報告と修正の指示、カスタムコマンド（/start・/done など）の使い方
   残さないもの: 確認のための短い質問、要約の依頼、言い換え、「yes」「進めて」などの返事、設定の選択肢を 1 つずつ聞いただけのもの（まとめて 1 件にする）
3. トークン・API キー・パスワード・個人のデータ・PC 固有のパスは、その部分を省いてください。会話記録のファイルは変更しないでください。
4. 結果（PR 番号など）は、会話の内容と `gh pr list --state all` から分かる範囲で書いてください。

次の形の markdown を、1 つのコードブロックだけで出力してください。プロンプトは原文の言語のまま、結果は日本語で書いてください。最後に、記録が残っていた期間（最初と最後の日付）を 1 行で書いてください。

### <日付> <タスク ID または目的>（Claude Code: <PC の種類>）
> <プロンプトの原文。長いログは「（ログを貼り付け）」と書いて省く>

- 結果: <何が決まり、何ができたか。PR があれば番号>
```

## 3. 貼り付けたあと
Mac の Claude Code（このリポジトリ）で次のように頼む。

```text
次の記録を docs/ai-usage/<自分の ID>.md に統合してください。日付順に並べ、重複は 1 件にまとめ、「記録がない期間」の表を更新してください。
（ここに 1・2 の結果を貼る）
```
