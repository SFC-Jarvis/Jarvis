# 音声サービス ⇄ 画面のイベント

p3 の最初に、音声（A）と画面（B）で決めて記入する。決まるまでは画面側はモックで進める。

前提（決定済み）: マイクの音声はブラウザで取得して音声サービスへ送る。読み上げの音声もブラウザで再生する（Windows の人は WSL の中で音声サービスを動かすため）。

決めること:
- 接続方法（Pipecat のクライアント SDK / WebSocket など）とエンドポイント
- 画面 → 音声: 録音開始・停止、承認の返事（はい・いいえ）
- 音声 → 画面: 文字起こし（途中・確定）、AI の返答テキスト、読み上げ開始・終了、エラー
- 各イベントの名前と JSON の形（例を 1 つずつ書く）
